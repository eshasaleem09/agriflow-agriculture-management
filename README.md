# 🌱 AgriFlow — Agriculture Management System

AgriFlow is a modern agriculture management dashboard designed to bring essential farm-management information and activities into one interface. It provides a clean, responsive experience for viewing crop information, weather conditions, farm analytics, supplies, buyers, and harvest orders.

## 🚀 Live Demo

Live Website:[Open AgriFlow](https://agriflow-agriculture-management-qkl3xi46o-esha-saleem.vercel.app/)

GitHub Repository:[View Source Code](https://github.com/eshasaleem09/agriflow-agriculture-management)

## ✨ Features

* **Dashboard:** View key farming information in one place.
* **Crop Management:** Browse and manage crop information.
* **Weather:** Access the weather section of the dashboard.
* **Analytics:** Explore agricultural data through visual charts.
* **Supplies:** View farm supply information.
* **Orders:** Access order-related information.
* **Buyers:** Explore the buyers section.
* **Harvest & Orders:** View harvest summaries, schedules, and order information.
* **Responsive Layout:** Navigate the application on desktop and smaller screens.
* **Interactive Navigation:** Move between the application's different sections.

## 💻 Run Locally

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm before starting.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/eshasaleem09/agriflow-agriculture-management.git
   ```

2. Navigate into the project directory:

   ```bash
   cd agriflow-agriculture-management
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

To create a production build, run:

```bash
npm run build
```

The generated production files will be available in the `dist` directory.
